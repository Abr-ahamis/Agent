# Task

## Request
Audit and materially improve the cybersecurity agent repository, prioritizing practical modular skills, routing/composition, tool intelligence, workflows, responsible execution boundaries, tests, and documentation.

## Inputs
Existing repository documentation, security references, catalog, shell scripts, and evaluation scenarios.

## Deliverables
1. Architecture audit and constraints.
2. Operational, discoverable skill corpus and selector.
3. Tool selection data and workflow guidance.
4. Authorization/scope enforcement boundary.
5. Automated unit/scenario tests.
6. Updated documentation and verification evidence.

## Boundaries
Local repository changes only. No network target testing, dependency installation, or edits to read-only `.agents/`.
